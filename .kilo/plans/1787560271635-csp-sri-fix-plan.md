# CSP & SRI Fix Plan

## Goal
Fix the two MDN HTTP Observatory failures for `trackwise-chi.vercel.app`:
1. **Content Security Policy (CSP)** — remove `'unsafe-inline'` from `script-src` and add `object-src 'none'`.
2. **Subresource Integrity (SRI)** — add `integrity` hashes to all external `<script>` tags.

## Approach
Use **CSP nonces for inline scripts** + **convert inline event handlers to external JS with data attributes**.

Inline scripts that contain Jinja2-rendered data produce different HTML per request, so static hashes are impossible. Nonces allow specific inline scripts without opening the door to arbitrary inline code. Inline event handlers (`onclick`, `onchange`, etc.) are converted to external JS listeners triggered by `data-` attributes.

## Tasks

### Task 1: CSP nonce infrastructure
**File:** `app/__init__.py`

1. In `create_app()`, add a `before_request` handler that generates a random nonce (e.g. `secrets.token_urlsafe(16)`) and stores it in `g.csp_nonce`.
2. Update `set_security_headers()`:
   - Remove `'unsafe-inline'` from `script-src`
   - Add `'nonce-{g.csp_nonce}'` to `script-src`
   - Add `object-src 'none'`
   - Keep `'unsafe-inline'` in `style-src` (scan does not flag it; 32 inline `style` attributes are pervasive and out of scope)
3. Add a `context_processor` that injects `csp_nonce = getattr(g, 'csp_nonce', '')` into all templates.

### Task 4: Convert inline event handlers to external JS + data attributes

**4a. Create `static/js/form-handlers.js`** for global patterns:
- Forms with `data-confirm="..."` → intercept submit and call `confirm()`
- Selects with `data-autosubmit="true"` → auto-submit parent form on change
- Buttons/links with `data-action="print"` → call `window.print()`

**4b. Create page-specific JS files** for complex logic:
- `static/js/dashboard.js` — reads chart data from a `<script type="application/json" id="chart-data">` tag or `data-` attribute, initializes Chart.js
- `static/js/inventory.js` — search filtering, modal population
- `static/js/journal-entry-form.js` — line item add/remove, debit/credit totals
- `static/js/journal-entries.js` — Bootstrap modal trigger for delete confirmation
- `static/js/payments.js` — payee toggle, bill filter, line item filter (reads `ALL_LINE_ITEMS` from a `data-` attribute)
- `static/js/purchases.js` — purchase row management with event delegation for dynamically added rows
- `static/js/sales.js` — sale row management with event delegation for dynamically added rows

**4c. Update templates**:
- Replace `onsubmit="return confirm('...')"` with `data-confirm="..."`
- Replace `onchange="this.form.submit()"` with `data-autosubmit="true"`
- Replace `onclick="window.print()"` with `data-action="print"`
- In `sales.html` and `purchases.html`, replace inline event handlers in dynamically generated HTML (`onchange`, `oninput`, `onclick`) with `data-` attributes and attach listeners via event delegation in the external JS files
- Replace Jinja2 data embedded in inline scripts with `<script type="application/json" id="...">` tags or `data-` attributes on parent containers
- Load external page scripts in `{% block scripts %}` with `<script src="..." nonce="{{ csp_nonce }}"></script>`
